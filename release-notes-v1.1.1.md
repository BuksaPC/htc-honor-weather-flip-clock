## HTC Weather Flip Clock — v1.1.1 (Oct 2026)

**Built for current Android (target SDK 36).** Same Sense flip clock + Open-Meteo weather as v1.1.0, with **flip timing** aligned to the minute change.

### New in v1.1.1

- **Flip on the minute** — Digits no longer jump to the new minute 1–2 seconds before the flip animation. Ticks fire at the minute boundary; refresh paths keep the old digits visible until the flap runs.

### Still included (v1.1.0)

- **Manual city** — Search/add cities; selection persists across weather refresh.
- **°F / °C** — Unit toggle in widget settings.
- Live **Open-Meteo** weather, reliable time updates, **minSdk 24** · **targetSdk 36**.

- **Package:** `com.htc.widget.weatherclock`
- **versionCode:** `663091310`
- **versionName:** `10.10.1059527-android36-v1.1.1`

### Install

1. Download **`HTC-WeatherClock-10.10.1059527-android36-v1.1.1.apk`** below (or **Releases → Latest**).
2. Install over v1.1.0 with the same debug signature, or uninstall any older Weather Clock first if prompted.
3. Re-add the **4×2 Weather Clock** widget if needed; open **settings** for city and °F/°C.
