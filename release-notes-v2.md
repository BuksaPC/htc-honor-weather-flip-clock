## HTC Weather Flip Clock — android36 (Oct 2026 update)

**Built for current Android (target SDK 36).** Same Sense flip clock + Open-Meteo weather, with **widget settings** that work on modern launchers (One UI, Nova, etc.).

### New in this release

- **Manual city** — In widget settings, pick a city from your list or **search and add** a city (e.g. San Diego, Los Angeles). The widget is meant to **stay on that city** instead of jumping back to GPS/current location after weather refresh.
- **°F / °C** — Temperature unit toggle in settings; the widget updates to match your choice.

### Still included from v1

- Live **weather** (Open-Meteo)
- **Flip** digit animation on time changes
- **Time updates** reliably (no stuck clock)
- **minSdk 24** · **targetSdk 36**

- **Package:** `com.htc.widget.weatherclock`
- **versionCode:** `663091309` (superseded by **v1.1.1** / `663091310`)
- **versionName:** `10.10.1059527-android36`

### Install

1. Download **`HTC-WeatherClock-10.10.1059527-android36-v1.1.0.apk`** from the assets below (or use **Releases → Latest**).
2. Allow installs from unknown sources if prompted.
3. If install fails, uninstall any older **Weather Clock** app first, then retry.
4. Add the **4×2 Weather Clock** widget, open **settings**, set **city** and **°F/°C** as you like.

See repository **README** for screenshots and full details.
