## HTC Weather Flip Clock — android36

**Built for current Android (target SDK 36).** Restores Sense flip clock + working weather on phones where the original widget freezes or shows no weather.

### What works in this release

- Live **weather** (Open-Meteo)
- **Flip** digit animation on time changes
- **Time updates** reliably (no stuck clock)
- **minSdk 24** · **targetSdk 36**

- **Package:** `com.htc.widget.weatherclock`
- **versionCode:** `663091309`
- **versionName:** `10.10.1059527-android36`

### Install

1. Download **`HTC-WeatherClock-10.10.1059527-android36.apk`** from the assets below.
2. Allow installs from unknown sources if prompted.
3. If install fails, uninstall any older **Weather Clock** app first, then retry.
4. Add the **4×2 Weather Clock** widget from the widget picker.

See repository **README** for screenshots and full details.
